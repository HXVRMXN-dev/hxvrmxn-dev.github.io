Getting started

From download to running server

  1. Open the resource you want from the sidebar and read through the overview so you know what it needs.
  2. Follow that page's Installation section — download, drop it in your resources folder, and set convars if it has any.
  3. Add ensure <resource-name> to your server.cfg, restart the resource, and check the console for errors.
